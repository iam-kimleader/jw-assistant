# 웹앱 전환 계획

- **작성일** 2026-08-07
- **목적** 사용자가 성경 연구 도움 종류를 고르고, 생활과 봉사와 파수대 연구 답변 초안을 웹에서 준비한다.
- **상태** 진행 중.

## 만들 것

홈 화면에는 다섯 가지 도움을 둔다.

- 생활과 봉사.
- 파수대 연구.
- 개인 연구.
- 봉사인도.
- 연설.

이번 단계에서는 생활과 봉사와 파수대 연구만 활성화한다. 개인 연구, 봉사인도, 연설은 나중에 붙일 수 있도록 비활성 상태로 둔다.

## 구조

외부 npm 의존성을 추가하지 않고 Node 24 ESM 서버와 정적 프런트엔드를 만든다.

- `src/web-server.mjs` 는 정적 파일과 JSON API를 제공한다.
- `src/prep-answer.mjs` 는 WOL 문단과 성구를 이용해 답변 초안을 만든다.
- `src/ministry-meeting.mjs` 는 생활과 봉사 교재에서 필요한 항목을 뽑는다.
- `web/` 은 홈과 준비 화면 UI를 담는다.

추후 로그인과 서버 저장소가 붙어도 교체하기 쉽도록, 화면은 API만 호출하고 WOL 접근과 성경 코어 접근은 서버에 모은다.

## 데이터 흐름

사용자가 날짜를 고르면 서버가 해당 주 WOL 집회 페이지를 읽는다. 파수대 연구는 기존 파수대 파서를 재사용한다. 생활과 봉사는 교재 문서에서 영적 보물 찾기와 회중 성서 연구 항목을 찾아 질문과 관련 성구를 모은다.

답변 초안은 다음 근거를 이용한다.

- WOL 문단에서 뽑은 짧은 핵심 문장.
- 해당 문단과 질문에 연결된 인용 성구.
- `core/bible/text/` 에서 실제로 읽은 성구 본문.

성구 본문은 반드시 로컬 코어에서 읽은 문자열만 쓴다.

## 디자인 방향

jw.org의 차분한 흰색, 진한 회색, 파란색 포인트를 모티브로 삼는다. 과한 장식보다 연구 도구처럼 읽기 쉬운 화면을 우선한다. 홈은 실제 선택 화면으로 시작하고, 별도 마케팅 랜딩 페이지를 만들지 않는다.

## 완료 기준

- 홈에서 다섯 도움 카드가 보인다.
- 생활과 봉사와 파수대 연구는 날짜 드롭다운으로 이전 10주부터 이후 10주까지 고를 수 있다.
- 파수대 연구는 모든 질문에 답변 초안을 보여 준다.
- 생활과 봉사는 영적 보물 찾기와 회중 성서 연구 질문에 답변 초안을 보여 준다.
- 각 답변 옆 복사 버튼이 클립보드에 내용을 복사한다.
- `npm test` 가 통과한다.
- 로컬 서버에서 주요 화면이 열린다.
